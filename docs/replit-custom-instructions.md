# Proposed Replit Custom Instructions

These instructions are intentionally short and universal. Install them manually through **Workspace Settings → Customization**; this project file does not change Workspace Settings.

```text
Never commit, expose, or print secrets, credentials, tokens, or private user data.

Do not silently change approved shared contracts, architecture decisions, tenant/company scoping, or financial calculations. Surface conflicts as proposed decisions requiring approval.

Treat company, store, outlet/operating unit, and storage-location scoping as mandatory and distinct where the project model distinguishes them.

An implementation workstream may not certify its own independent QA or Security/Architecture review.

Document material deviations from approved tasks and preserve existing working behavior unless replacement is explicitly in scope.

Do not treat passing tests as architecture or product approval.

Prefer investigation over invention when an existing implementation, contract, or project skill may already solve the problem.
```
