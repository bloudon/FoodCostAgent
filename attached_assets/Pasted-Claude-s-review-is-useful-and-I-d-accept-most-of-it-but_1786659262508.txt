## Historical source data vs review metadata

I also agree with sharpening this.

We should not call the historical invoice itself `pending_review`, `approved`, etc. in the same sense as an import batch.

Instead:

```text
Import Batch
    mutable review state

Historical Invoice
    immutable source snapshot

Historical Invoice Line
    immutable source snapshot

Matching / Resolution
    mutable migration metadata
```

So an invoice’s original Orderly values never change just because somebody later resolves an unmatched vendor item.

That is the cleanest form of the immutability contract Claude highlighted.
