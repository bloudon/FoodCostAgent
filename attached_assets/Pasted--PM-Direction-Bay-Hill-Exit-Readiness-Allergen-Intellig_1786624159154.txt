# Step 4 — Allergen Intelligence

Create this as a separate Significant product capability.

It is not an Orderly migration field and should not be coupled to the Bay Hill extractor.

## Product Contract

Calories remain under the existing model:

`Menu Item → Calories`

Do not redesign calorie handling as part of this work.

Allergens belong to inventory ingredients:

`Inventory Item → Allergens`

Recipes then derive their allergen indicators from the ingredients used in the recipe:

`Inventory Items → Recipe Ingredients → Derived Recipe Allergens`

Menu items linked to recipes may display the derived recipe allergen information.

Do not create another independent allergen source of truth on linked menu items.

## Structured Inventory-Item Allergens

Support structured allergen attributes for the major allergen classes rather than free-text-only storage.

The model should also leave room to distinguish, where reliable source information exists:

- Contains
- May contain / cross-contact
- Not identified

Do not automatically translate absence of a known allergen into an “allergen-free” or “safe for allergy” guarantee.

## Recipe Derivation

Normal rule:

> Recipe allergen set = union of the allergen attributes of all inventory items used by that recipe.

Example:

Chicken Parmesan:

- Bread crumbs → Wheat
- Parmesan → Milk
- Egg wash → Egg

Derived:

`Milk • Egg • Wheat`

If an ingredient allergen classification changes, affected recipes should automatically reflect the change.

Do not maintain manually duplicated allergen lists on every recipe unless an explicit exception/override model is later approved.

## Review / Provenance

Because allergen information has food-safety consequences, distinguish between:

- suggested/unreviewed data
- source-confirmed data
- chef-reviewed data

If AI, OCR, vendor data, or package-label capture suggests allergens:

`Source / AI suggestion → Review → Confirmed ingredient allergens → Recipe derivation`

AI should not silently convert a suggestion into authoritative allergen information.

Track review/provenance sufficiently to know why an allergen indication exists.

## Menu Item Behavior

For menu items tied to a recipe:

`Recipe derived allergens → Menu Item display`

For menu items without a sufficiently defined recipe, do not invent allergen results from unrelated menu text.

A state such as:

`Allergen information incomplete`

is preferable to an unsupported safety conclusion.

## Orderly Comparison

While Bay Hill discovery continues, determine whether Orderly actually supports structured allergen data at:

- ingredient level
- recipe level
- menu-item level

If Orderly does not, classify this as FnB **NET NEW / differentiation**.

If Bay Hill actively uses an Orderly allergen capability we have not yet discovered, reassess it as an Orderly Exit Readiness requirement.

Do not delay #1086/#1087 while that determination is made.
