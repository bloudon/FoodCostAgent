## Revised model

The database only needs:

```ts
subscriptionPlan: "platform" | "enterprise";
subscriptionStatus:
  | "trialing"
  | "active"
  | "past_due"
  | "canceled"
  | "incomplete";
billingInterval: "monthly" | "annual" | "custom";
```

The operating mode can initially be derived:

```ts
function getOperatingMode({
  subscriptionPlan,
  activeOperatingLocationCount,
}: {
  subscriptionPlan: "platform" | "enterprise";
  activeOperatingLocationCount: number;
}) {
  if (subscriptionPlan === "enterprise") {
    return "enterprise";
  }

  return activeOperatingLocationCount >= 2
    ? "multi_location"
    : "single_location";
}
```

## Important distinction

Count only actual operating locations or stores:

* Restaurant locations
* Branches
* Separately operated units

Do not count:

* Walk-ins
* Freezers
* Dry storage
* Bars
* Wine cellars
* Prep rooms
* Other inventory storage locations

A single restaurant with 20 storage locations is still a Single Location customer.
