## 1. Adoption happens from authoritative source evidence, not merely because a row is "later"

The defect is cross-batch adoption, but chronology is not authority.

A missing vendor product may be adopted only when current source evidence proves:

- canonical inventory item
- Orderly source/property
- vendor identity
- source SKU / Item Code

- no conflicting existing vendor product/source mapping

Do not create a vendor product simply because a later batch contains a superficially similar row.

If the later batch is still pending, it may contribute to the READ-ONLY preview, but it must not become persisted catalog truth merely because it was parsed.

The actual adoption point must respect the approved import/batch lifecycle.
